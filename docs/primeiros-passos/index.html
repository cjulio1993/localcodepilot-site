Primeiros passos com LocalCodePilot no Windows

Guia para a versão 0.4.0-alpha.6, distribuída como ZIP portátil para Windows 10/11 x64. O produto está em alpha: consulte as limitações e notas da versão antes de usar.

1. Baixe a release oficial

Abra as notas da release 0.4.0-alpha.6 e baixe o arquivo LocalCodePilot-0.4.0-alpha.6-windows-x64.zip. Confira os requisitos e a lista de arquivos da release.

2. Confira o SHA-256

No PowerShell, execute o comando abaixo usando o caminho real do arquivo baixado. Compare o valor Hash com o SHA-256 publicado na mesma release. Os valores precisam ser iguais; se forem diferentes, não execute o arquivo e refaça o download oficial.

Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\LocalCodePilot-0.4.0-alpha.6-windows-x64.zip" -Algorithm SHA256

3. Extraia e abra o aplicativo

Extraia o ZIP para uma pasta de sua escolha e abra o executável incluído. Não execute diretamente dentro do ZIP. Confira o nome e as instruções do executável na release.

4. Escolha uma pasta de projetos

No aplicativo, selecione os diretórios que contêm seus projetos locais. A descoberta identifica tecnologias e estruturas; dependências e arquivos de build são excluídos da busca. Comece com um projeto de teste conhecido para conferir o reconhecimento.

5. Confira requisitos antes de iniciar

Revise a tecnologia detectada, os requisitos do projeto e o comando sugerido. Uma detecção não significa que todos os runtimes ou ferramentas necessários já estejam instalados. Use as instruções do próprio projeto para preparar o ambiente.

Nos serviços compatíveis, use as ações disponíveis para preparar dependências, iniciar ou interromper a execução e acompanhar os logs. Confira a porta e a URL mostradas pelo aplicativo.

Quando algo não inicia

  • Consulte o log e identifique a primeira mensagem de erro.
  • Confirme que o runtime exigido pelo projeto está disponível.
  • Se a porta estiver ocupada, consulte o guia de portas em uso no Windows.
  • Ao relatar uma falha, informe versão do app, Windows, tecnologia e passos para reproduzir. Remova tokens, senhas e dados privados dos logs.

Containers e ajuda na Alpha 6

O LocalCodePilot pode validar, iniciar, consultar estado e logs, interromper e construir ambientes com Docker ou Podman. O comando é mostrado antes da confirmação; o motor precisa estar instalado e em execução.

A página Ajuda resume o primeiro uso, os estados do projeto, bancos, containers e os passos para investigar uma falha.
