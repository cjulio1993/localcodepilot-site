Getting started with LocalCodePilot on Windows

This guide covers version 0.4.0-alpha.9, available as an installer and a portable ZIP for Windows 10/11 x64. The product is in alpha: review its limitations and release notes before use.

1. Download the official release

Open the 0.4.0-alpha.9 release notes and download the installer LocalCodePilotSetup-0.4.0-alpha.9-windows-x64.exe (recommended) or the portable ZIP LocalCodePilot-0.4.0-alpha.9-windows-x64.zip.

2. Verify SHA-256

In PowerShell, run this command with the actual path to your downloaded file. Compare Hash with the SHA-256 published in that release. They must match. If they differ, do not run the file; download it again from the official release.

Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\LocalCodePilotSetup-0.4.0-alpha.9-windows-x64.exe" -Algorithm SHA256

3. Install and open the application

Run the installer: it installs the app in your user folder, without administrator rights, and adds a Start menu shortcut. The files in this version are not digitally signed yet; if Windows shows "Windows protected your PC", click More info and then Run anyway. If you prefer the ZIP, extract it to a folder and open LocalCodePilot.exe, not from inside the ZIP.

4. Find your projects

Open Projetos (Projects). LocalCodePilot finds projects in your common user folders. If a project is missing, use Adicionar pasta (Add folder).

5. Follow the project's action

A freshly cloned project shows as Parado (Stopped). If libraries are missing, use Instalar dependências (Install dependencies); if the language is missing, use Preparar ambiente (Prepare environment). When the project is ready, use Iniciar (Start). The first time you run a project command, the app shows Iniciar este projeto? (Start this project?) with the command and asks you to confirm.

When the site answers, the card shows its address and Abrir site (Open site). Use Ver logs (View logs) to see the command output.

When a service will not start

  • Read the log and find the first error.
  • Confirm that the required runtime is available.
  • For port conflicts, read the Windows port troubleshooting guide.
  • When reporting a bug, include the app version, Windows version, technology and reproduction steps. Remove tokens, passwords and private data from logs.

Containers and help in Alpha 9

LocalCodePilot can validate, start, inspect status and logs, stop, and build environments with Docker or Podman. The command is shown before confirmation; the engine must be installed and running.

The Help page summarizes first use, project states, databases, containers, and the steps for investigating a failure.
