Getting started with LocalCodePilot on Windows

This guide covers version 0.4.0-alpha.5.1, a portable ZIP for Windows 10/11 x64. The product is in alpha: review its limitations and release notes before use.

1. Download the official release

Open the 0.4.0-alpha.5.1 release notes and download LocalCodePilot-0.4.0-alpha.5.1-windows-x64.zip. Check the requirements and release asset list.

2. Verify SHA-256

In PowerShell, run this command with the actual path to your downloaded file. Compare Hash with the SHA-256 published in that release. They must match. If they differ, do not run the file; download it again from the official release.

Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\LocalCodePilot-0.4.0-alpha.5.1-windows-x64.zip" -Algorithm SHA256

3. Extract and open the application

Extract the ZIP to a folder of your choice, then open the included executable. Do not run it from inside the ZIP. See the release for the executable name and instructions.

4. Select a project folder

Select directories containing local projects in the app. Discovery identifies technologies and structures while excluding dependencies and build artifacts. Start with a familiar test project to check detection.

5. Check requirements before starting

Review the detected technology, project requirements and suggested command. Detection does not mean every required runtime or tool is already installed. Follow the project's own setup instructions.

For supported services, use the available actions to prepare dependencies, start or stop execution and follow logs. Check the port and URL reported by the app.

When a service will not start

  • Read the log and find the first error.
  • Confirm that the required runtime is available.
  • For port conflicts, read the Windows port troubleshooting guide.
  • When reporting a bug, include the app version, Windows version, technology and reproduction steps. Remove tokens, passwords and private data from logs.

Alpha limitations

Dockerfile and Compose projects can be identified and diagnosed. LocalCodePilot does not yet install Docker or Podman, download images or run containers.

In-app updates begin with this alpha. Users on alpha 4 or earlier must install alpha 5 manually before using this flow for subsequent updates.
