Preguntas frecuentes

¿LocalCodePilot es open-source?

Sí. El código está disponible en GitHub para consulta y contribución. Consulta la licencia del repositorio para los términos de uso.

¿Qué versiones de Windows son compatibles?

La alpha pública está disponible para Windows 10 y 11 x64. También hay un DMG universal experimental para Mac Intel y Apple Silicon; Linux no forma parte de esta versión.

¿La aplicación ejecuta containers Docker o Podman?

Sí. Alpha 7 ejecuta operaciones de Compose con Docker o Podman después de mostrar el comando y solicitar confirmación. El motor debe estar instalado y en ejecución.

¿Puedo consultar registros y procesos locales?

Sí. La alpha permite iniciar y detener servicios compatibles, consultar registros y trabajar con puertos alternativos. La compatibilidad depende de la tecnología y los requisitos del proyecto.
